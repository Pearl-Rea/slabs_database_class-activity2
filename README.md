\## Activity 2: Types of Information Systems and IT Landscape



\### What is Information Systems?

A set of interrelated components that collect, process, store, and distribute information.



\### Types of Information Systems

1. TPS - Sales daily transactions
2. MIS - Reports for managers
3. DSS - Helps make decisions
4. ESS - Dashboards for executives



\### IT Landscape

Sales generate most data -> Finance -> Executive
